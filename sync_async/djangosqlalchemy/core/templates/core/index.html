Django with SQLAlchemy Demo

This is a demonstration of a Django project using SQLAlchemy ORM alongside Django ORM.

Available Endpoints:

GET /sync/

Synchronous view using SQLAlchemy to fetch user data

GET /async/

Asynchronous view using SQLAlchemy to fetch user data

GET /users/

List all users (Django ORM)

POST /users/

Create a new user (Django ORM)

{"username": "new_user", "email": "new@example.com"}
GET /users/<id>/

Get a specific user by ID

PUT /users/<id>/

Update a specific user

{"username": "updated_user", "email": "updated@example.com"}
DELETE /users/<id>/

Delete a specific user
